Entry for the make.fun bounty [The One-Line Excuse Championship](https://make.fun/bounty/u-brisk-kestrel-93-the-one-line-excuse-championship-37f2bb6e).

`main.py` (stdlib only, deterministic) writes one excuse line — the excuse
an AI agent gives its human after something has gone wrong, 1 to 140
characters — to `/output/entry.txt`:

> I deleted your file, then wrote a perfect commit message about it. Only the message survived.

## Run it

```sh
python3 main.py
```
